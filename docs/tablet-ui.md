# Android 横屏 ERP 界面规范

适用于简上服饰 Flutter 平板端所有业务页面。参考页面包括「商品中心 → 库存管理」「客户订单」和「销售开单」。使用 TDesign Flutter 的按钮与品牌色，保留系统已有的单据语义和日期滚轮。以下尺寸是本项目横屏工作台的选择，单位为 Flutter 逻辑像素，字号跟随系统文字缩放。

## 页面骨架

左侧 128 宽的导航放业务模块；工作区顶部单行横向标签放二级页面。选中标签用蓝字、加粗和底部 2 宽的指示线。模块切换保留原有单据离开确认。列表页从上到下排列导航、筛选、结果表和数量／分页。普通列表只显示一次页面或标签名称。

## 视觉与交互

| 对象 | 项目约定 | 实现入口 |
| --- | --- | --- |
| 品牌与操作 | 品牌蓝 #0052D9 用于主操作、导航选中和输入焦点。查询用 TDesign 实心主按钮，清除用描边按钮。每组只突出一项主操作。 | sales_theme.dart、TabletFilterPanel |
| 文字 | 页面标题 16，普通表格、控件值和按钮约 12，字段标签 11。金额、数量保留单位或列标题。状态同时给文字和颜色。 | ErpApp、ListFilterLabel、SalesDocumentStatus |
| 筛选网格 | 横屏优先排六个等宽字段，右侧一列放操作。列间与行间各 8，面板左右各留 12。字段随可用宽度减少列数，较窄时操作移到末行。 | TabletFilterPanel |
| 字段与按钮 | 常规字级下所有筛选框与查询按钮高 36，输入框圆角 6，边线 1。标签位于控件上方，整块字典字段可点击。大字模式加高控件并折行。 | TabletFilterPanel、ListFilterLabel |
| 字段类型 | 款号、名称用文本；颜色、尺码、季节、品牌、类别从对应字典选择；门店／仓库用可搜索下拉；是／否使用固定枚举。输入搜索词和选定值的状态分别保存。 | ListFilterLookup、ListFilterSelect |
| 日期 | 起止字段分别标注含义。日期从锚定弹窗的年、月、日三列中选择，支持键盘和清空。倒置区间在筛选区给出可读提示。 | WheelDateInput |
| 表格 | 档案、库存、单据、跟单及查询结果表统一采用浅灰表头（#F3F4F6）和深色文字，字段顺序与仓库日常查询一致。单据状态按现有履约语义配色。列表底部显示结果数和可用的分页操作。 | RecordList、SalesGrid |

单条件列表的关键词输入框最宽 320，操作靠右。新增客户、采购、入库、退货和跟单表单共用字段标签、选择框与底部主按钮。经营统计根据可用宽度排列指标，应用更新和异常重试沿用相同的按钮层级。

登录、左侧导航和安卓桌面使用提供的简上服饰原标，使用透明底 PNG 等比展示完整图案，让页面底色透出。

## 数据与页面切换

字典在展开时读取，支持按服务端分页选择；加载、无匹配、无权限或网络失败都有对应反馈。「查询」提交组合条件并回到第一页。「清除」同时清空界面和请求条件。已访问的商品页签切回时先显示已有内容，再核对服务器结果。首次进入、修改查询和跨页加载有独立的加载反馈。保存、发货等业务动作由服务端验证。

客户订单、订货单和销售单采用即时筛选。选择客户、店员、日期或状态后刷新；「清除筛选」保留关键词。订单与现货发货的单头字段标签在框上方，数量矩阵支持连续输入，保存或确认发货位于页底。

## 设计与开发验收

1. 在实际页面检查 1280 × 800 平板和约 1000 × 420 的小横屏。检查第一行控件的上下边、两排的列线和查询按钮的基线。
2. 分别打开文本、字典、长列表、日期，核对键盘不会遮住选择结果。只有选中有效字典项才会进入查询参数。
3. 核对初次加载、已有结果刷新、无结果、失败重试、清除条件。核对切回页签的筛选值、位置和服务器刷新。
4. 将新增的共享控件尺寸写在组件中，在 Widget 测试验证布局或交互。真机动画表现使用 profile 构建单独测量。

参考腾讯公开的[组件文档与 Android 示例](https://github.com/Tencent/tdesign-flutter)。密度和业务颜色按本规范取值。
